Versi 8.4

Cara Main

  1. Buka menu Akun dan isi nama perangkat.
  2. Perangkat A tampilkan kode atau QR-nya. Perangkat B masukkan kode A atau scan QR A.
  3. Perangkat A muncul popup Terima Lokasi. Tekan Yes.
  4. Perangkat B muncul Diterima. Nyalakan GPS di kedua HP.
  5. Menu Start Lokasi muncul. Tekan Start untuk membagikan jejak, Finish untuk berhenti.
  6. Pasangan bisa diputuskan kapan saja di menu Akun.
